# 情報更新による損失の変化とモデル差の交互作用 v1

主要解析、施設別・NZ、共有学習、全国の追加区間補正の結果を見た後に決めた探索的分析である。研究質問は変えない。古い汎用モデルと最新の従来モデルの損失比だけでは、「汎用モデルの方が情報の古さに頑健」と「新しい情報を代替できる」を区別できないため、同じ対象で4予測を揃えて調べる。新しいデータやモデル、APIは使わない。

## 標本・比較

ドイツ全国・地点・NZの実公表入力、ネイティブ予測、56日参照に限る。汎用モデルはChronos-Boltと公開後のTimesFM、従来参照は3方法固定合成、6方法固定合成、過去成績選択、利用できる国の共有学習。古い入力は1/2週前。各条件で同じ対象について汎用の古い/最新、従来の古い/最新が全てある例を結合する。方法ごとに欠けた例やゼロ損失の件数を保存し、対象の損失が0という理由では除外しない。過去成績選択では年齢によって選択法も変わりうるため、単一アーキテクチャの比較とは扱わない。共有学習も情報量が異なる。

評価は既存の全テストと共通2026年。ドイツ全国・地点、NZ全国・地域を分ける。同一入力、同じ終端の改訂、観測終端の延長、観測終端の差0/1/2/3週以上、病原体を保存する。地点の2026年継続標識と検出限界標識の層も残す。層を無作為な介入と解釈しない。

## 指標

WISと点予測MAEで、同じ4予測の対象に揃えた平均損失を使う。個々の例の誤差比の平均は取らない。

- 汎用の情報の古さによる損失比 = mean(FM古い)/mean(FM最新)。
- 従来の同じ比 = mean(従来古い)/mean(従来最新)。
- 上の比の比。1未満は、この標本で汎用の相対的な損失増が小さい。
- 損失増の差 = mean(FM古い−FM最新)−mean(従来古い−従来最新)。
- 元の交換可能性に関する比較 = mean(FM古い)/mean(従来最新)。併せてmean(FM最新)/mean(従来最新)を保存。

最後の2つの比と汎用の情報年齢比の関係が恒等式になることは発見ではない。同一入力なら同じモデルの古い/最新予測は一致するため、情報年齢比1と増分0は整合性の検証であり効果の発見ではない。主な経験的結果は、同一入力を除いた群や全標本の増分と交互作用である。平均損失が0で比が定義できない場合は欠測とし、再抽出も含め件数を保存する。

同じ発行週の全単位をまとめた4/8/12週移動ブロックを2,000回再抽出し、4予測を同じ再抽出に入れる。主区間は8週、seed12012に条件の固定ハッシュを加える既存方式。独立の区間が1をまたぐかを比べて交互作用の検定にしない。多重比較調整、因果効果、非劣性、費用対効果は主張しない。

結果がどちら向きでも、情報の古さへの相対的な頑健性と、最新情報を持つ別の方法の代替可能性を分けて報告する。主要結果を置換せず、主要解釈が変わる場合だけ要旨に探索的と明記する。各ジョブ30分以下・同時2、既存の容量・期限を維持する。
