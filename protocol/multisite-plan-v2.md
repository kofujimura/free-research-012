# 多施設計画 v2：評価前の観測継続を適格条件に追加

multisite-plan-v1.mdを保持して継承する。施設の予測精度はまだ計算していない。E017/E019の監査では個別施設ファイルが2021年からの履歴を保持し、施設名の数は現在測定が続く施設数と一致しない。v1の『過去16週の測定がある』だけでは評価開始より前から更新されていない履歴だけの施設が入るため、**2025-06-18の公表版の直近8週に少なくとも4週の正値がある**ことも各施設・病原体の適格条件に加える。時期は当該公表コミットのUTC日を終端とし、8つの水曜の週を数える。これは評価開始前の情報だけを用いる条件である。

v1の人口5万人以上、16週以上、名前のSHA順で最大80施設、2026年開始時に観測のある組の補足条件、全期間の欠測・停止の保持は維持する。新旧の適格条件による候補件数は両方保存し、成績のよい施設を採ることはしない。生の施設名を掲載しないラベルは匿名化の保証ではなく、出典の公表データから対応を確認できる分析用IDである。

全国ファイルの変更コミットと個別ファイルの変更コミットは、対象の2024-12-18以後で79件ずつ完全に一致することを別のgit logで確認した。したがってE019の79版は個別施設ファイルについても全変更版であり、全国版だけの日程を仮定して取りこぼしたものではない。
