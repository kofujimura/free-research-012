# 入力の同一性・丸め・補完の追加点検 v1

全国・地点・NZの主要な損失と追加比較を見た後の探索的な自己点検である。元の入力ハッシュは保存した倍精度の対数値と日付で定義されている。一方、汎用モデルへの入力はfloat32へ変換する。保存履歴が異なっても、この変換後に同一になる可能性を数える。主要表の「同一入力」は保存履歴の同一性であって、量子化後のテンソルの同一性を全て数えたとは解釈しない。

## 入力監査

全テストの実公表ケースで、0/1/2週前入力と最新入力を同じ単位・病原体・対象に結合する。両方が入力可能であることを要件とし、参照値や予測誤差によって選ばない。日付列と長さが一致する場合に、倍精度の完全一致、float32変換後の完全一致、対数値の最大差0/1e-6/1e-3/0.01以下を全て数える。閾値は生物学的同等性を表さず、最良の閾値を事後に選ばない。日付終端が異なる場合は予測距離も変わるため、数値が近くても同一履歴としない。

個々の入力の補完割合、元の実測数、定数か、末尾2点が同一かも保存する。既存E038の全ユニーク入力の集計には較正期間と全国の将来版診断も含まれることを明確にし、テストの実公表入力に限定した頻度と区別する。

## 損失の感度

同じ56日参照、ネイティブの汎用候補（公開後）と最新従来参照の対象を揃える。元の3/6方法・過去成績選択、および地点/NZの共有学習を保持する。情報年齢1/2週、全テスト・2026年、国/地域/地点を分ける。

全対象、両方の入力に補完がない群、両方の補完割合0.1以下、両方0.25以下、いずれか0.25超、同じ日付でfloat32一致する群、同じ日付で最大差1e-6以下の群を全て報告する。点予測MAEとWIS、元の週ブロック4/8/12週・2,000回。入力の層は測定頻度・流行時期に依存し、無作為な比較でも補完の因果効果でもない。主要結果は変更しない。追加のAI推論・API・データ取得は不要。上限30分・同時2・10GiBを維持する。
