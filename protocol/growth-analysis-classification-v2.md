# 上昇検出の計画上の位置付けと補足実装 v2

plan-v2の45行付近は、2倍上昇の元の方法のROCを予定の補足と明示していた。E037は全体をexploratory:trueとしたが、この広い実験メタデータを、元の2倍上昇のROCまで事後の着想だったという意味に使わない。元の論文草稿の表現も訂正する。2倍について元の7方法のROCは事前計画、他の上昇比率・追加方法は探索的、AUCという要約量は主要結果の後に追加した探索的指標とする。ROCがテスト全体からの遡及的な識別指標であり、運用可能な閾値の検証と異なる点は変えない。

E037に元の単体従来4方法のROCが含まれていなかったので、保存されたネイティブ予測から全12方法に拡張して再計算する。E037と主要の通知結果は消さない。再計算の入力CSVはround_tripの浮動小数点復元を指定し、閾値の同点処理を保つ。元の3方法固定合成を参照とする2倍の通知件数が主要E011と一致するかを照合する。全ての主要比率や成功失敗の記録を維持し、予定の指標の欠落を補うものである。
