# 保存済み全公開版の地点週集計の追加検証

主要・探索的実験と全43段階の通し再計算が終了した後の自己点検である。残る弱点だった原データ集計の標本確認を、保存済みの全79版・固定コホート全系列へ拡張する。新しい予測・指標選択・データ取得は行わない。

E026の標準ライブラリによる別実装を使い、選択する系列と版だけを全てへ広げる。正の実測値、日別の重複対数平均、木曜〜水曜の週ラベル、週内の日別対数平均、定量下限標識、実測日数、公表日の除外規則を変えない。全ての対象週についてE023の保存Parquet値と照合し、最大絶対対数差・標識差の許容差は元と同じ1e-12、日数と日付は厳密一致とする。照合した版数・系列数・週数を保存し、独立した外部再現とは呼ばない。

30分・同時2実験・10GiBの上限を守る。出力は小さなサマリーとログだけで、新しい大規模ファイルは作らない。失敗すればそのまま残し、科学的な結果への影響を判断して提出する。元の計算結果や期待表を検証に合わせて変更しない。
