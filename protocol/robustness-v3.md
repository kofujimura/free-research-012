# 時刻代理追試の学習ラベル可用時点 v3

v2の精度再計算前の実装点検で明確にした。E046の入力は構築済みだが、公表時刻をずらした条件の成績はまだ算出していない。参照値の定義と評価用truth_deadlineは変えない。一方、過去の残差や従来法の選択に用いるラベルは、公表を遅らせた仮定でも利用できなければならない。

そのため学習の可用時刻をmax(元の成熟締切, その参照公表版のGit時刻+24/48時間)とする。評価用の参照値は同じに保つ。新しいtraining_available_at列を保存し、過去成績選択と残差較正に限ってこの時刻を使う。元の時刻仮定、地点、NZ、非正規化系列のデータにはこの列がなく、元の成熟締切による処理を維持する。E046を上書きせず、新しい入力準備実験で同じケースと値、追加の可用時刻を保存してから評価する。

これは先の成績を有利にする修正ではなく、時刻の仮定と学習時点を整合させるための追記である。他のv2の条件を維持する。
