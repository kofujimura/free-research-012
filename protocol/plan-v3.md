# 計画 v3：日付整合性とETS指定の修正（予測前）

v1/v2を保持する。本計画はv2の全仕様を継承し、以下だけ変更する。予測精度はまだ計算していない。E005は入力構築時の曜日検査で停止し、モデル推論は実行していない。

E004の曜日監査を精査すると、最初期の版は週次ではなく各曜日の値を含む。また2026-05-20の1版では、全病原体の全履歴の日付が金曜になっている。前後の版は水曜である。この版の日付を自分で2日前に移すことはせず、**週次水曜の指標として利用可能な最新の版**を各病原体について採る。対象の正値の行の日付が全て水曜で、重複がない版を利用可能とする。直近版がこの条件を満たさなければ、同じ情報締切以前の直前の利用可能版へ戻る。参照版も同じ規則とする。飛ばした版と理由、発生したケース数を保存して示す。これは生の公開版から測定の意味を守るための、予測の前に決めた適格条件である。初期の毎日データは主要期間の入力にならないが、全履歴を週次と仮定しない。

このため『最新』とは『本計画の週次指標として利用可能な公表版の最新』であり、日付に不整合がある最新のファイルを無条件に使った結果ではない。欠陥の原因は調べておらず、訂正値を作成していない。品質検査で失う情報更新も情報鮮度の制約として集計する。病原体が未掲載の期間は利用可能な版が存在しないので欠測とする。

v2のETS指定に矛盾があった。model=ZZZは誤差型も自動選択するが、説明は加法誤差としていた。対数値に加法誤差を使うという方針に合わせ、AutoETSのmodelを**AZN**（加法誤差、傾向自動、季節なし）に確定する。その他の指定はv2を維持する。これは予測結果を見た後のモデル選択ではない。

主要予測はこのv3に結び付ける。入力構築の再実行から本計画を適用する。
