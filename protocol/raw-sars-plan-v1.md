# 非正規化SARS-CoV-2指標への探索的検証 v1

主要結果と参照版の感度を見た後に設定した。地点・NZの精度はまだ集計していない。最終公開版の公式README（固定6586326、95〜118行付近）を再点検すると、`viruslast`と週報には非正規化値を使い、正規化で改善したデータ品質を確認できなかったことが明記されている。主要解析は過去の公表履歴と列の意味を維持するためSARS-CoV-2の正規化系列を選んでいたが、それだけでは現場の現在の指標への適用範囲が不足する。主要解析を取り替えず、非正規化のSARS-CoV-2全国集計を追加する。

新しい列構成（viruslast_normalisiertが別にある版）ではviruslastを非正規化として使う。古い構成ではnormalisierung=neinと明示されたSARS-CoV-2行だけを使う。正規化済みの古い値を『原値』と読み替えてつながない。不明な古い構成・値のない版は不適格とし、直前の適格版を使う。最初に利用できる実公表版をraw-availability.jsonに保存する。後日の版に含まれた過去の原値を、当時利用できた入力として使わない。

対象はSARS-CoV-2だけ。元の較正開始・テスト期間、金曜12UTCの発行、直前/次の水曜、情報年齢0/1/2週、16実測・104点・未来16週、主要56日参照と28/84日・固定最終版を維持する。入力は実公表版だけとし、主要の診断用最終版切断入力は今回は実行しない。正の測定値、曜日、欠測処理も元の規則を継承する。入力がない時期はno_source_releaseとし、最初から成績のある期間だけを黙って選ばない。

同じ全7方法と追加従来3方法を使う。3/6方法固定合成と過去成績選択、ネイティブと主要の残差分位点補正、全テスト/2026年/TimesFM公開後、週ブロック4/8/12を保持する。正規化・非正規化の結果を比較するときはSARS-CoV-2の共通の対象週・発行・情報年齢に揃える。対数なので単位の尺度差はある程度共通化できるが、両指標を同じ生物学的正解と扱わない。差を正規化だけの因果効果と断定しない。全国集計では地点・検査室の全期間の平均差による調整も公式に記載されている。これは既知の処理であり、本研究が発見した処理とはしない。

署名が異なる入力だけが追加のローカル推論を必要とする。少数の入力で、各ジョブ30分・2並行・10GiB内で実施する。新たな外部データ・API・人間実験は不要。新規性を誇張せず、現実的な指標で結論が残るかという自己点検として扱う。主要解析の限界を変える結果の場合は、探索的であることを明記して要旨に反映する。
