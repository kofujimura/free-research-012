# 解析実装の具体化（精度の集計前）

plan-v3（v2/v1を継承）の解析部分を具体化する。E008/E009の生成件数と成功/失敗だけ確認した。予測精度・検出性能を集計していない時点で作成する。

- 比較の単位は発行日×病原体×対象日。候補と年齢0の従来合成が両方ある標本に揃える。欠測を0損失として扱わない。nativeとcalibratedを別に集計する。
- 濃度の残差較正は対数上の点予測に残差分位点を足す方式で、生成した未来全体の経路を較正するものではない。したがって**上昇検出はnativeの経路だけ**で行う。レベル補正だけで、基準の過去値と未来値の差を改善したとは扱わない。診断用finalized_prefixには運用可能な較正を装わず、nativeだけを出す。
- 較正残差・通知閾値には、同じモデル・病原体・情報年齢・対象週の位置で、8週の参照締切が発行時点より前になったケースだけを使う。最大52のうち最後の例を時間順に採る。参照値が欠測の例、非数値の予測を利用しない。
- ネイティブ予測の上昇スコアは、対象日の予測中央値と14日前の予測中央値（観測範囲内ならその入力値）の差。過去の非上昇例だけから通知閾値を作る。未来のイベントを使って閾値を決めない。検出については通知可能な共通標本の比較も保存する。
- 全体、3病原体、2対象週、2026年、増加/横ばい/減少、情報集合が完全に同じ/終端のみ同じ/新しい観測あり、を予定の層別とする。公開後のTimesFMの比較を別にし、公開前の運用性能とは呼ばない。
- ブートストラップは各週の候補損失の合計、比較損失の合計、ペア数を一組とする。対象期間の全金曜を格子にし、層別で標本のない週は合計0・件数0として保持する。非循環の連続した4/8/12週ブロックの始点を復元抽出し、必要数を連結して元の週数で切る。候補/比較の合計損失比、損失差/ペア数を計算し、2000回の2.5/97.5%点を示す。分母0の反復を除き、その件数を報告する。
- 同一入力は保存された入力の署名の一致。同一予測は9分位点の最大差≤1e-7。入力に既に対象日を含むケースも別に数え、主要予測から除く。これらの件数をモデル優劣の数値と共に生成する。
- WISは2×9分位点の平均ピンボール損失。区間表示から独立に実装したWISと照合する。正規分布の予測値の利用と対数の指数変換を混同しない。主要評価は対数のままなので指数の平均/中央値の差を持ち込まない。
- 解析は保存されたTSV・入力・予測JSONから再計算し、外部接続をしない。予測や将来値をこのセッションの文章で判定する処理はない。
