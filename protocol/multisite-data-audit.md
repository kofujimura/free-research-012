# 多施設への追加検証：データ監査計画（主要結果後、探索的）

全国集計で得た『入力が更新されたかで平均比較が変わる』という結果が、全国の集計・補正に固有かを調べる準備を行う。主要研究質問は維持する。全国の少数の倍増例だけで検出能力を語れないことも追加の動機である。施設の比較順位や臨床的な警報効果は目的にしない。

取得対象は同じ公式リポジトリの amelag_einzelstandorte.tsv。CC BY4.0、RKI/Umweltbundesamtを明記。既に確認した公式文書では施設・病原体・採水日・ウイルス量・接続人口・定量下限のフラグ等であり、個人を対象とするデータではない。§12.5を適用し、再識別・世帯への推定はしない。成績は施設名を出さず病原体別と全体の集計に限る。

最初の監査は、2025-06-18公表版（主要評価開始前）と2026-10-14固定版の2ファイル。生のTSVのSHA-256とGitオブジェクトを照合し、gzip(mtime=0)で内容を変えずに保存する。URL、公表コミット日時、取得日時、圧縮前後のSHA-256とバイト数を記録する。列、病原体、日付、施設数、人口の欠測・範囲、定量下限フラグの有無を一覧にする。予測や施設の成績は計算しない。

この監査で意味を確認した後、予測前の別計画で週次化・対象施設・評価を固定する。予定する一般化は、評価開始前の情報だけで選ぶ十分な規模の下水処理施設での予測である。暫定の適格条件は接続人口5万人以上、各病原体の週次値16週以上。施設数が多い場合は最大80施設を名前のSHA-256の順に選び、成績を見て選ばない。人口閾値は個人・少数世帯を扱わないことと実務対象を明確にするためであり、適用先を大規模施設に限定する。この条件の変更が必要なら施設の精度を見る前に記録する。

本格的な追加検証では、較正開始の情報年齢2週を再現するため2024-12-18から固定最終版までの公表版を使う見込み。原ファイルを圧縮保存し、全体容量を随時測る。10GiBに近づいたら取得を停止し、得られた範囲を記録する。各取得は90秒、監査全体1800秒、同時実験最大2。既知の部分クローンのcommit-graph不整合を避ける設定だけを自分の取得コマンドに適用する。外部の設定を変更しない。
