# 全国集計の追加検証 v1（主要結果の観測後、探索的）

主要結果EV0097を見て立てた追加計画。主要計画と結果は変更しない。目的は、暦上の情報年齢、実際の観測追加、過去値の改訂、将来の集計尺度の変化という代替説明を分け、従来法の比較を強めること。新たな社会課題には拡張しない。

## 1. 同じ発行時点での情報更新の分解

情報年齢1/2週の実入力Aと年齢0の実入力Cに加え、**年齢0の公表版をAの最終観測日で切った入力B**を作る。Bには発行時点より後の公表値を一切使わない。A→Bは既存履歴の改訂・採否の変更を反映し、B→Cは新たな週の観測を追加する。この順序に条件付けた比較であり、現実の公表工程を変えた因果効果ではない。逆順で古い尺度と新しい値を混ぜた人工系列は作らない。

A/B/Cの各予測器のWIS・MAEを同じ対象週・参照版で計算し、損失A−損失B、損失B−損失Cを保存する。差が足し合わさること自体は恒等式であり発見ではない。符号・大きさ・病原体・上昇/減少・更新の空白への依存を観測する。既存の同一入力は保存予測を再利用し、新しい入力だけを推論する。比較モデルは主要実験の全7方法、同じ設定。

## 2. 濃度の尺度の改訂に関する測定妥当性

古い情報の最終観測日を共通の基準日とし、予測分位点から各入力でのその基準日の対数濃度を引く。正解側も同じ参照公表版の対象日−基準日の対数差とする。これにより、対象日の絶対濃度だけでなく、既知の時点からの変化の予測を同じ基準で測る。WIS/MAEと8週移動ブロック区間を出す。基準日の値がない場合は欠測として数える。主要の絶対濃度の誤差を置き換えず、将来の公表尺度の変化を当てることと動向の予測が異なるかを調べる。

恒等式である『レベル予測誤差＝基準からの変化の誤差＋基準日の改訂』の分解は妥当性の照合にのみ使う。基準日の改訂幅の分布、時期、モデル比較への影響が経験的な対象となる。56日参照と固定最終版を両方見る。

## 3. 強い従来法の追加

以下を同じ386入力に適用する。主要の従来合成は維持する。

- AutoTheta：StatsForecast、加法の季節分解。履歴104点以上なら年周期52、未満は非季節。モデル選択は入力だけで行う。
- SeasonalNaive：52点以上なら前年同週、未満ならNaive。区間の尺度は1年差分が3個以上あるときその標準偏差×√ceil(h/52)、それ以外は主要Naiveと同じ尺度。少標本の尺度を隠さない。
- 動的調和回帰：年周期365.2425日のsin/cosを外生変数とするAutoARIMA。履歴78点以上ならFourier次数K=0,1,2,3から学習区間のAICcで選択し、未満はK=0。ARIMAの探索上限は主要計画を維持する。未来のカレンダーは既知であり、未来の測定値を使わない。選ばれたK、AICc、失敗を保存する。
- 拡張した固定合成：主要の3方法と上記3方法の分位点の等重み平均。6方法が全てある場合だけ作る。
- 過去の成績による従来法の選択：上記6方法とNaiveから、病原体×情報年齢×対象週の位置ごとに、発行時点までに8週参照の締切を通過した直近26例（最低12例）の平均WISが最小の方法を選ぶ。同点は方法名の辞書順。選択理由と使用例数を保存する。テスト期間全体の最良モデルを遡って選ぶことはしない。

追加比較では最新情報の拡張合成と過去成績選択を参照にし、1/2週古い各基礎モデルと比較する。較正は主要計画と同じ方法で追加モデルにも適用する。どれか一つの比較だけを選んで主張しない。

## 4. 上昇の定義への感度と識別性能

主要の2週倍増は維持し、探索的な比率1.1/1.25/1.5/2/3を全て報告する。各比率で過去の非上昇例から10%通知率を意図した閾値を同じ方法で作り、共通標本でテストの通知率・見逃しを比較する。より有利な比率を主要な結果に格上げしない。臨床的な警報閾値という主張はしない。

予定していたROC曲線も作り、実際の誤通知率0.1以下での識別性能を確認する。テスト全体から作るROCは、過去に利用できた閾値ではない。病原体・対象週別、モデル共通の2026年を含めて、陽性/陰性が足りない条件はそのまま示す。
