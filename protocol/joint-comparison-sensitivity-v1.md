# 同じ評価期間と複数比較への感度 v1

主要結果・地点/NZ・共有学習・交互作用・入力品質を見た後の探索的自己点検である。履歴長の追加推論は実行中で、その集計結果はまだ見ていない。元の主要解析と公称区間を保持する。多数の探索的な交互作用の一部だけが区間1を除くことを、一般的な頑健性の証明としないために行う。

## 固定する範囲

元の最大104週の未補正予測、実公表入力、56日参照、WISだけを使う。両汎用モデルの重み公開後の共通期間（ドイツ2025-10-03以後、NZ2025-10-06以後）に揃える。全国と地点をドイツの同じ週で、NZ全国と地域をNZの同じ週で共同再抽出する。国を混ぜた独立事例数を作らない。

汎用2モデル×固定3/6方法参照×情報締切1/2週×国ごとの2集計水準、計16の4予測比較を各国の同じ比較群とする。各比較は古い/最新の汎用と古い/最新の従来の4予測がある同じ対象に限る。全体の同一入力という自明な例を避け、古い入力から最新入力に観測終端が延長した群を用いる。4予測の共通例数・対象系列・発行週を全て残す。過去成績選択と共有学習は学習状態の年齢が異なるため、この点検の比較群には入れない。

各比較で「汎用の古い/最新の損失比 / 従来の古い/最新の損失比」と「古い汎用 / 最新従来」の2統計量を同時に扱う。各国32統計量であり、国間や全ての論文中の比較を包括した区間とは呼ばない。

## 計算

4/8/12週の移動ブロック、各10000回、seed12012から国・ブロックごとの固定ハッシュを使う。主要の感度表示は8週で、ブロック長を有利な結果から選ばない。同じ国の全系列・対象週・モデル・比較に同じ発行週の再抽出を適用する。

通常の百分位区間に加え、各再抽出について全32統計量の `abs(log(再抽出値)-log(元の値))` の最大値を取り、その95百分位をcとし、全統計量に `exp(log(元の値)±c)` を示す。これは共同ブートストラップの最大偏差による探索的な同時区間であり、小標本の時系列における厳密な被覆率を保証しない。ゼロ分母・非正値・非有限値を含む再抽出は比較群全体で無効とし、件数を記録する。元の値でこの問題があれば該当比較を除外せずエラーとして残す。

対照は同じ期間・同じ4予測の通常の区間である。元のChronos全期間との違いは、時期と同時比較の両方を変えるため、この2段階を区別して報告する。主な解釈は、限られた探索的所見がこの点検を経てどこまで残るかであり、区間が1を含むことを無効果や同等性の証明とはしない。主要計画の仮説を事後に置換せず、新しい独立検証とも呼ばない。

新しいデータ取得・推論・AI APIは不要で、保存された分位点のスコアから再計算する。1実行は30分以内、同時実験2本まで、保存出力は小さな表と比較群の索引に限る。
