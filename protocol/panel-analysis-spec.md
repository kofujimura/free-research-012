# 拡張の解析仕様（地点・ニュージーランドの予測精度集計前）

元の拡張計画を変更せず実装を明確にする。地点の一次入力集計照合E026は6系列・4版で2,140週値、最大対数差8.89e-16、標識割合差0で完了した。同一研究者の別実装であって独立再現ではない。NZのE027は6版を不適格としたうえで国1・地域5の6系列を準備した。これらの数値は入力の確認であり予測精度ではない。

全て探索的。比較の結合キーには単位IDを含める。6方法固定合成、過去成績による選択、残差較正は同一単位の履歴内だけで実行し、地点・地域をプールして学習しない。従来法選択は利用可能になった56日参照の直近26例、最低12例。較正は最大52例、最低12例。どちらも参照の締切が発行時点より前のものだけ。未来の参照の欠損有無を現時点の予測の出力条件に使わない。

ブロック再抽出はドイツが金曜、NZが月曜の全発行週のカレンダーで実行する。各週に含まれる全単位・病原体・対象週を同じ再抽出に入れる。系列数を独立の流行数とみなさない。主な比は同じ対象を両方法で評価できる例の損失平均比であり、単位ごとの平均比ではない。全期間と共通の2026年、3種類の最新従来参照、0/1/2週の情報年齢、4/8/12週ブロックを全て保持する。NZ全国と地域を混ぜた値を国全体の性能として論じず、level別を提示する。

同一入力、同じ終端で改訂あり、新しい週の観測ありを数える。観測終端の前進0/1/2/3週以上も分ける。地点では事前の2026年継続標識、参照の検出限界未満の標識割合0または0.5以上、入力終端の標識割合0.5以上を分ける。標識0はRNA真値が確定したという意味ではない。欠測・範囲外・参照欠測を意図した全条件の分母と併記する。

上昇の解析は元の計画の比率1.1/1.25/1.5/2/3を全保存する。各単位・病原体・対象位置・方法・情報年齢内で、締切が過ぎた過去の非上昇例の90百分位から通知閾値を作る。較正履歴が足りない条件を落とした件数も保存する。ROCは同じテストの実測2週変化とネイティブの点予測変化から作り、同じスコアの組をまとめる。AUCと実測誤通知率0.1以下で到達できる最大感度は**テスト全体から遡った識別指標**であり、過去に利用できた閾値の成果とは区別する。陽性がない条件はROCを計算しない。陽性の行数と異なる発行週数を両方保存する。国と地域の重複した情報や、重なる2週の上昇を独立事象として数えない。入院・臨床警報・利用者への効果は測定しない。
