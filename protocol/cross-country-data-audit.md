# 異なる公表制度のデータ監査（探索的）

ドイツ国内の追加だけでは公表制度の一般性を確認できないため、公開の政府・研究機関の資料を検索した。RIVMの見つかった研究用リポジトリは2020〜2022年の解析で、基礎モデル公開後の実公表版の評価には使えない。Eawagの公開呼吸器ウイルスCSVはCC BY4.0だが13コミットであり、定期的な運用公表版が十分あるか未確認。一方、ニュージーランドPHF Science（旧ESR）の公式リポジトリは179コミット、CC BY4.0、国・地域の週次値を公開し、公式の説明では2024年8月以降は隔週公表としている。この制度差は『1週古い』情報が同一になりやすいかという既存の研究質問に直接関係する。

まずNZの国・地域の**下水データだけ**を通常の公開Gitで調べる。対象URLは https://github.com/ESR-NZ/covid_in_wastewater 、対象ファイルはREADME.md、data/ww_national.csv、data/ww_regional.csv。個別施設、症例、地理ポリゴン、他の資料は取得しない。資料の表記が実データと一致するか、週末日、病原体、単位、利用条件、公表日時・変更版の数、範囲、欠測を確認する。予測精度はこの監査で計算しない。

研究起点2026-10-18T15:26:38Z以前の最新版で固定し、その時点までに記録された変更版を保存する。Git日時は公表時刻の代理であり独立した公開日時の証明ではない。通常のGit clone/readに限り、robotsやアクセス制限を回避しない。URL、コミット、日時、SHA-256、原CSV、利用条件を保存する。初期と固定時のREADMEも確認し、旧版に別条件があれば従う。PHF Science指定の帰属表示を成果に記載し、承認・推奨を受けたと示唆しない。

その後、精度を見る前に、入手できた時系列に対応する発行日・対象週・評価終端・参照版を別計画へ固定する。ドイツと単位・週の定義・対象人口が違うため、国の優劣を順位付けせず、各データ内でのモデルと情報の比較を検証する。利用できる実版が不足なら、未完の一般化として記録して無理に後日版で代用しない。

§12.5を適用する。国・地域の集計のみで個人・少数世帯の再識別はしない。新しい有料API・外部AI・外部投稿を使わない。監査ジョブは1800秒、1回の公開Git取得は90秒、最大2実験並行、全体10GiBを維持する。
