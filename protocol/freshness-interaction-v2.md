# 情報年齢の交互作用 v2：学習状態の区別

v1に基づく全国のE093を確認した後、地点・NZの交互作用を計算する前の解釈の限定である。v1の数値、比較、層、終了条件は維持し、旧版とE093を残す。主に解釈と報告上の中心比較を明確にする。

「古い」は入力する単変量の数値履歴の締切を意味する。固定した3/6方法合成は、その履歴内で各成分を当てはめる。一方、過去成績選択は発行時点までに成熟した過去の成績を年齢別に使い、同一の現在入力でも選択成分が異なりうる。共有学習は同じ発行週のモデルを使うため、古い入力に対しても発行時点までの他系列・参照情報で学習したモデルを使っている。後者2つについて、学習や選択に使う情報全体を入力締切まで巻き戻したという意味ではない。

したがって、相対的な頑健性に関する中心比較は固定3方法・固定6方法とする。過去成績選択と共有学習も全数値を残すが、入力履歴だけを古くした運用戦略の補足比較と明記する。共有学習は国ごとに情報量も異なるため、汎用モデルとのアーキテクチャの因果比較ではない。この限定は、主要の「古い汎用モデル対最新の従来参照」という比較を変更しない。

同一入力なら汎用モデルおよび固定合成・同じ週の共有モデルの予測が一致することは点検する。過去成績選択には同じ入力でも異なる方法を選ぶ余地があるため、一致を要件にしない。これを入力データの改訂や新しい観測と混同しない。追加の解析結果を見た後で中心比較を入れ替えない。
